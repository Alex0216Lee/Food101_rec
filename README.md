# Intelligent Recipe Recommendation Platform Based on Swin Transformer

> An AI-powered food image recognition and recipe recommendation system integrating computer vision, deep learning, and Transformer-based image classification.

---

## Overview

This project develops an intelligent recipe recommendation platform based on food image recognition.

Given an input food image, the system performs image classification using deep learning models and identifies the corresponding food category. The predicted category is then integrated into the recommendation workflow to provide related recipe suggestions.

The project focuses on exploring the effectiveness of Transformer-based architectures, particularly **Swin Transformer**, for food image classification and practical recommendation applications.

The research outcome was accepted and presented at **CVGIP 2025 — The 38th Conference on Computer Vision, Graphics, and Image Processing**.

---

## Key Features

- Food image classification
- Food-101 dataset preprocessing
- Deep learning model training and evaluation
- Swin Transformer-based feature learning
- Comparison of multiple image classification models
- Prediction pipeline for unseen food images
- Integration of classification results into a recipe recommendation workflow
